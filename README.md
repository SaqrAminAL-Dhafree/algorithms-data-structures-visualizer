📌 نبذة عن المشروع

هياكل البيانات + الخوارزميات + التنفيذ البرمجي + التمثيل البصري + التفاعل مع المستخدم

ويتيح ذلك دراسة طريقة عمل الخوارزميات وملاحظة نتائجها بصورة عملية بدل الاكتفاء بقراءة الكود أو دراسة الخطوات نظريًا.

🌳 هياكل البيانات
1. Binary Tree — الشجرة الثنائية
يحتوي المشروع على تطبيق لبنية Binary Tree مع مجموعة من العمليات الأساسية.
العمليات
- إنشاء شجرة ثنائية كاملة اعتمادًا على عدد العقد.
- Pre-Order Traversal
- In-Order Traversal
- Post-Order Traversal
- حساب Tree Height.
تمثيل العقدة
تعتمد العقدة على:
Node
├── Value
├── Left
└── Right
وهذا يسمح بتمثيل العلاقة بين العقدة وأبنائها الأيسر والأيمن.

🔎 خوارزميات البحث في الرسوم البيانية
🔵 Breadth-First Search — BFS
تُستخدم خوارزمية BFS لاستكشاف الرسم البياني بطريقة البحث بالعرض.
تبدأ من عقدة محددة، ثم تستكشف العقد القريبة قبل الانتقال إلى المستويات التالية.
يساعد العرض البصري على متابعة:
- العقد التي تمت زيارتها.
- ترتيب الاستكشاف.
- الانتقال بين مستويات الرسم البياني.
🟢 Depth-First Search — DFS
تُستخدم خوارزمية DFS لاستكشاف الرسم البياني بطريقة البحث بالعمق.
تقوم الخوارزمية بالتعمق في المسار قبل الرجوع لاستكشاف المسارات الأخرى.
ويوفر التطبيق تمثيلًا بصريًا لعملية الزيارة، مما يساعد على فهم آلية DFS عمليًا.
🌐 Minimum Spanning Tree
Kruskal's Algorithm
يتضمن المشروع تطبيق خوارزمية Kruskal لإيجاد:
Minimum Spanning Tree — MST
تعتمد الخوارزمية على اختيار الحواف وفق أوزانها مع تجنب تكوين دورات غير ضرورية.
🔗 Union-Find / Disjoint Set
يستخدم المشروع مفهوم Union-Find لإدارة المكونات المتصلة والمساعدة في تحديد ما إذا كانت إضافة حافة معينة ستؤدي إلى تكوين دورة.
🛣️ خوارزميات أقصر المسارات
Dijkstra's Algorithm
يتضمن المشروع خوارزمية Dijkstra لحساب أقصر المسارات في الرسوم البيانية الموزونة وفق آلية الخوارزمية.
وتُستخدم لإظهار كيفية الوصول إلى المسارات ذات التكلفة الأقل انطلاقًا من عقدة محددة.
Bellman-Ford Algorithm
يتضمن المشروع أيضًا خوارزمية Bellman-Ford لحساب أقصر المسارات.
وجود أكثر من خوارزمية للمسارات الأقصر داخل التطبيق يوفر أساسًا عمليًا لدراسة طرق مختلفة لحل مشكلة المسار الأقصر.

▶️ تشغيل المشروع
المتطلبات
لتشغيل المشروع محليًا، تحتاج إلى:
- Windows
- Visual Studio
- دعم C# / Windows Forms
- بيئة .NET Framework المناسبة للمشروع
خطوات التشغيل
1. استنساخ المستودع:
git clone https://github.com/SaqrAminAL-Dhafree/algorithms-data-structures-visualizer.git
2. فتح ملف:
WindowsFormsApp2.sln
3. فتح الحل باستخدام Visual Studio.
4. استعادة/تحميل مكونات المشروع إذا طلب Visual Studio ذلك.
5. بناء المشروع باستخدام:
Build → Build Solution
6. تشغيل التطبيق باستخدام:
Start / F5
يعتمد تشغيل المشروع على إعدادات بيئة Visual Studio وإصدار .NET Framework المتوافق مع ملف المشروع.
